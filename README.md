# 📚 NLP Exercises Repository

## 🚀 Introduction

This repository contains practical exercises, scripts, and projects developed during the **Special Topics in Computer Science II** course, which focused specifically on **Natural Language Processing (NLP)**. This course is part of the [Computer Science Degree](https://github.com/Danilo-Js/scl-app/My-Computer-Science-Course), aiming to update students' knowledge through the study of state-of-the-art research and practical implementations in NLP.

The course covered fundamental aspects of NLP, including:
- Introduction to NLP
- Levels of Analysis in NLP
- Implementation Approaches
- Practical NLP Applications

## 📂 Repository Structure

- **Scripts**: Contains basic scripts to illustrate fundamental NLP concepts.
  - `contaLinhas_arquivoTeste.py`: Simple Python script to count the number of lines in a given file.
  - `retorna_alfabeto.py`: Python function that returns the alphabet set from a given string.

- **Trabalho01**:
  - `Pessoa.fst2` and `Pessoa.grf`: Files related to Finite State Transducers (FST) and graphical representation used for modeling language patterns.

- **Trabalho02**:
  - `N-Gramas_Predicao_2023.py`: Script implementing an N-gram language model for text prediction.

## 🛠️ Requirements

- Python 3.x
- Basic knowledge of NLP concepts

## 📖 Usage

To run the scripts:

```bash
python Scripts/Exercicios\ simples/contaLinhas_arquivoTeste.py
python Scripts/Exercicios\ simples/retorna_alfabeto.py
python Trabalho02/Codigo-Base-Predicao/N-Gramas_Predicao_2023.py
```

Ensure necessary input files (`arquivoTeste.txt`, `corpus_bruto.txt`) are placed correctly in their respective directories.
